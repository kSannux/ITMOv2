Возникшие проблемы:
- необходимость обновить Opencode до 2.0.20.
- несоотвествие API mcp версии >=2.0 в скрипте сервера mcp.
- несоотвествие раннера POSIX sh, вследствие невозможность вызова через sh.

Решения:
- переход с MCP на FastMCP и адаптация к его API.
- разделение mcp на инфтерфейса CLI(для демонстрации) и stdio(для Opencode).
- запуск mcp через Opencode в venv.
