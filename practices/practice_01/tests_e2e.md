# E2E-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Подтверждение |
|---|---|---|---|---|
| Позитивный | Доступен endpoint /api/reviews; есть валидный unified diff | POST /api/reviews с {diff} | Ассистент возвращает Summary, до 3 Risks с file/line/evidence, и Checks | P1-02 результат |
| Негативный | Доступен endpoint /api/reviews | POST /api/reviews с {} | AS IS: 500 с KeyError; TO BE: 422 | Diff TRAINING_PR, Checks C1 |
| Граничный | Большой diff | POST /api/reviews с большим diff | Ответ может быть ограничен (по политике сервиса); ассистент отмечает ограничение как открытый вопрос | Master Prompt — открытые вопросы |

## Как использовали AI

 - Для чего: описать e2e-сценарии для позитивного, негативного и граничного случаев по diff и Master Prompt v1.
 - Строка в [`prompts.md`](prompts.md): P1-03
- Что проверил студент и какие исправления поручил агенту: сценарии e2e соответствуют Master Prompt v1 и P1-02, без предположений вне diff; формат ответа API согласован как JSON с comment{summary, risks, checks}.
