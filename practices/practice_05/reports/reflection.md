# Рефлексия по ДЗ 5

## Что согласовали

Две спецификации сделали в отдельных чатах: одну для интерфейса, другую для
логики. Затем согласовали общий формат JSON, экспорт только текущей страницы
и видимых столбцов. При пустом результате кнопка недоступна, а причину
объясняет подсказка без тоста. При ошибке экспорта показывается тост.

## Что было сложным

В спеках были расхождения: интерфейс ожидал массив, а логика - объект
с метаданными. Ревью помогло найти эти проблемы. Общий контракт исправили,
но обе исходные спеки обновили после.

## Что понял

Spec Kit помог разложить работу на требования, план и задачи, но сам по себе
не гарантирует, что документы согласованы. Тестов логики тоже недостаточно:
скачивание, подсказки и ошибки нужно проверять в браузере.
