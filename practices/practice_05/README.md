# Практика 05 — экспорт таблицы в JSON

Локальный Flask-сайт с демонстрационной таблицей сотрудников. Поиск, сортировка,
пагинация и выбор столбцов выполняются в браузере. Экспорт передаёт снимок текущей
страницы Python-библиотеке и скачивает JSON с UTC-именем.

## Запуск

Из `practices/practice_05`:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Открыть http://127.0.0.1:5000. Остановка — Ctrl+C. Демо не предназначено для
публичного сервера: нет авторизации и постоянного хранения данных.

## Проверка

```sh
.venv/bin/python -m pytest
.venv/bin/python scripts/benchmark_export_json.py
```

В браузере:

1. Найти «Дизайн», скрыть ID, отсортировать имена, экспортировать. В файле только
   отображаемые строки и столбцы, порядок совпадает, фильтр записан в метаданных.
2. Очистить поиск, перейти на вторую страницу и экспортировать: других страниц в файле нет.
3. Ввести отсутствующее имя: кнопка disabled; при фокусе Tab на обёртке появляется
   «Нет данных для экспорта». Скачивания и тоста нет.
4. В DevTools включить Offline и нажать экспорт: появляется общий тост ошибки,
   кнопка восстанавливается. Вернуть сеть и повторить.
5. В DevTools замедлить сеть: во время запроса виден индикатор, повторный экспорт
   заблокирован. Можно изменить фильтр во время запроса: файл относится к снимку
   при нажатии, а кнопка после завершения соответствует новой странице.

Автотесты проверяют библиотеку и Flask endpoints; браузерные состояния проверяются
вручную по сценариям выше. Актуальный контракт: `specs/01-export-json/spec.md`.
