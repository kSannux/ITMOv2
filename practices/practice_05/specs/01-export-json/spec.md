# Согласованный контракт: Экспорт видимых данных в JSON

Короткое имя: export-filtered-json

## 1. Обзор и цели

Цель: предоставить пользователю возможность экспортировать только видимые (отфильтрованные/отсортированные) строки текущей таблицы в файл JSON одним действием, сохраняя их текущий порядок и набор отображаемых столбцов. Дополнительно включить в итоговый JSON метаданные об экспорте и применённых фильтрах для воспроизводимости выгрузки.

Бизнес-ценность: пользователи быстро делятся и анализируют актуальный срез данных без ручной очистки и с прозрачностью применённых условий отбора.

Вне объёма: пакетные/фоновые экспорты; экспорт в иные форматы (CSV/XLSX); управление правами, аудит и маскирование PII; механика построения фильтров и выборки данных; хранение и доставка файлов.

## 2. Акторы и контекст

- Актор: пользователь интерфейса таблицы данных.
- Контекст: экран/страница с таблицей, поиском/фильтрацией и кнопкой «Экспорт в JSON» на панели инструментов.

## 3. Согласованный формат JSON-файла (данные и метаданные)

Итоговый файл представляет собой JSON-объект с полями:

{
  "export_date": "ISO-8601 UTC строка с суффиксом Z",
  "total_items": целое число,
  "filters_applied": объект (словарь) применённых фильтров,
  "data": [
    { // объект строки, ключи соответствуют отображаемым столбцам
      "<column_key_1>": <value>,
      "<column_key_2>": <value>
    }
  ]
}

Требования и инварианты:
- export_date — момент формирования файла в UTC, ISO 8601, суффикс Z.
- total_items == длине массива data.
- filters_applied — копия словаря применённых фильтров на момент начала экспорта (формат — словарь/dict без модификаций содержимого; сортировка в метаданные не включается).
- data — массив объектов строк в текущем порядке таблицы (с учётом сортировки), но без явного описания правил сортировки в метаданных.
- Набор ключей в объектах строк соответствует текущему набору отображаемых столбцов; порядок ключей в JSON-объектах не гарантируется и не является значимым.

Имя файла по умолчанию: «export-YYYYMMDD-HHMMSS.json» (UTC время).

## 4. Контракт взаимодействия UI ↔ Логика

Входы функции формирования содержимого:
- filtered_items: список объектов строк (уже отражающих «видимые» столбцы/поля) только текущей страницы.
- filters_applied: словарь применённых фильтров; при отсутствии — пустой словарь. Значение filters_applied передаётся и возвращается как копия входного словаря без модификаций содержимого.

Выход функции: строка JSON (UTF-8) согласно разделу 3.

Охват данных:
- Экспортируется только текущая страница таблицы (видимые строки на текущей странице с учётом активных фильтров и сортировки на момент начала экспорта).

Ответственность слоёв:
- Логика формирует содержимое JSON (раздел 3), включая export_date/total_items/filters_applied/data, и возвращает строку. Сортировка и её правила не включаются в метаданные.
- UI инициирует скачивание файла, назначает имя по шаблону и обеспечивает UX (состояния кнопки/индикатор/подсказки/тосты).

## 5. Обработка ошибок и реакция UI

Правила:
- 0 видимых строк: кнопка «Экспорт в JSON» — нативно неактивна (disabled). Экспорт не инициируется; тост не показывается. Пользователь видит подсказку (tooltip) «Нет данных для экспорта» на фокусируемой обёртке вокруг disabled-кнопки при наведении/фокусе (обеспечивает доступность для клавиатуры/скринридеров).
- Логика выбрасывает ValueError("Empty dataset"), если была вызвана с пустым списком (на случай гонок/некорректных вызовов). UI не показывает тост «нет данных», а возвращает кнопку в обычное состояние; возможен лог/телеметрия.
- Ошибки сериализации/нормализации/прочие исключения логики: UI показывает тост «Не удалось выполнить экспорт. Попробуйте позже», кнопка возвращается в обычное состояние, возможна повторная попытка.
- Сетевые/инфраструктурные сбои (если экспорт инициируется через удалённый сервис): UI показывает тост «Не удалось выполнить экспорт. Попробуйте позже», повторная попытка доступна.

Состояния кнопки:
- Active — ≥1 видимая строка.
- Disabled — 0 видимых строк; действие невозможно; доступна подсказка (tooltip) «Нет данных для экспорта» на фокусируемой обёртке вокруг кнопки.
- Loading — экспорт инициирован; повторный запуск до завершения недоступен.

Доступность: кнопка фокусируема, управляется с клавиатуры; для disabled-состояния подсказка отображается на фокусируемой обёртке вокруг кнопки (для доступа с клавиатуры/скринридеров); подсказки/тосты не перехватывают фокус надолго и скрываются автоматически.

## 6. Пользовательские сценарии

Сценарий 1. Базовый экспорт (текущая страница)
1) Пользователь применяет фильтр; на текущей странице остаются видимые строки (например, 2 из 10 на странице).
2) Кнопка активна; пользователь нажимает «Экспорт в JSON».
3) Кнопка показывает индикатор загрузки; повторные клики блокируются.
4) Начинается скачивание JSON-файла. Файл содержит объект с export_date, total_items=2, filters_applied и data из 2 объектов в текущем порядке текущей страницы.
5) Кнопка возвращается в обычное состояние.

Сценарий 2. Пустой результат фильтрации (текущая страница)
1) Фильтр приводит к 0 видимых строк на текущей странице.
2) Кнопка — нативно disabled; экспорт не запускается.
3) Пользователь видит подсказку (tooltip) «Нет данных для экспорта» при наведении/фокусе.

Сценарий 3. Длительная операция
1) Экспорт запускается на большом наборе видимых строк текущей страницы.
2) Пока идёт экспорт, кнопка показывает индикатор; повторные клики блокируются.
3) По завершении пользователь получает файл.

Сценарий 4. Ошибка экспорта
1) Пользователь запускает экспорт.
2) Возникает ошибка (например, сеть недоступна или ошибка сериализации).
3) UI показывает тост «Не удалось выполнить экспорт. Попробуйте позже». Кнопка возвращается в обычное состояние.

## 7. Функциональные требования (тестируемые)

FR-1. Кнопка «Экспорт в JSON» активна при количестве видимых строк на текущей странице ≥1; иначе — нативно disabled.
FR-2. При нажатии активной кнопки запускается экспорт только текущих видимых строк текущей страницы; невидимые по фильтрам строки и строки на других страницах не попадают в файл.
FR-3. Во время экспорта кнопка отображает индикатор загрузки и не допускает повторного запуска до завершения.
FR-4. Если видимых строк = 0, экспорт не запускается; кнопка нативно disabled; при наведении/фокусе отображается подсказка (tooltip) «Нет данных для экспорта» на фокусируемой обёртке вокруг кнопки; тост не показывается.
FR-5. Экспортируемые данные следуют текущему порядку строк таблицы на текущей странице на момент начала экспорта.
FR-6. Имя файла по умолчанию формируется как «export-YYYYMMDD-HHMMSS.json» (на основе UTC времени).
FR-7. Возвращаемый JSON соответствует структуре: объект с полями export_date (ISO 8601 UTC), total_items, filters_applied (словарь), data (массив объектов строк); сортировка не включается в метаданные.
FR-8. Количество объектов в data равно количеству видимых строк на текущей странице на момент начала экспорта.
FR-9. Текстовые сообщения локализованы: «Экспорт в JSON», «Нет данных для экспорта» (tooltip), «Не удалось выполнить экспорт. Попробуйте позже» (тост).
FR-10. Доступность: кнопка доступна с клавиатуры; состояния фокуса/недоступности различимы; подсказка (tooltip) в disabled-состоянии отображается на фокусируемой обёртке и доступна для клавиатуры/скринридеров; подсказки/тосты автоскрываются и не перехватывают фокус надолго.
FR-11. Значения NaN/Infinity/−Infinity сериализуются в строки «NaN»/«Infinity»/«-Infinity» без выбрасывания исключений по этой причине.

## 8. Критерии успеха (измеримые)

- SC-1. Пользователь получает начало скачивания файла в ≤ 5 секунд в 95% случаев при объёме до 5 000 видимых строк на текущей странице.
- SC-2. В 100% случаев при 0 видимых строк на текущей странице кнопка недоступна (disabled) и при наведении/фокусе отображается подсказка «Нет данных для экспорта»; экспорт не инициируется.
- SC-3. В 100% случаев JSON содержит только видимые строки текущей страницы и соответствует текущему порядку таблицы.
- SC-4. Формирование содержимого JSON (без сети/IO) занимает ≤ 2 секунд в 95% случаев при объёме до 10 000 элементов.
- SC-5. В 99% случаев Unicode-символы в значениях корректно сохраняются и читаются потребителями без искажений.

## 9. Сущности и данные

- Row (строка): объект данных одной записи таблицы, содержащий только отображаемые столбцы.
- Column (столбец): атрибут строки; набор отображаемых столбцов определяет ключи объектов в data.
- ExportPayload: итоговый объект JSON (см. раздел 3).

## 10. Допущения

- На вход логики передаются уже «видимые» строки и только отображаемые столбцы текущей страницы; скрытые/служебные поля исключены.
- Временные значения нормализуются к UTC; при неизвестной таймзоне принимается UTC.
- Значения, не сериализуемые в JSON по стандарту, нормализуются по правилам домена (напр., Decimal → строка; Enum → строка/число; bytes → base64; NaN/Infinity → строки «NaN»/«Infinity»/«-Infinity»); при невозможности нормализации — исключение пробрасывается наверх с отображением общего тоста об ошибке.
- Запись на диск/выдача файла осуществляется слоем UI/интеграции и не входит в контракт логики формирования JSON.

## 11. Риски и зависимости

- Корректность и производительность фильтрации/сортировки таблицы до экспорта.
- Объём данных и ограничения среды на сериализацию и скачивание.

## 12. Тексты интерфейса (локализация)

- Кнопка: «Экспорт в JSON».
- Подсказка (tooltip, пустой результат): «Нет данных для экспорта».
- Тост (ошибка): «Не удалось выполнить экспорт. Попробуйте позже».

## 13. Приёмочные сценарии

AC-1. Базовый экспорт (текущая страница):
- Дано: на текущей странице 10 строк; фильтр оставляет 2 строки.
- Когда: пользователь нажимает «Экспорт в JSON».
- Тогда: скачивается файл .json, содержащий объект с export_date (ISO 8601 UTC), total_items=2, filters_applied и data из 2 объектов; порядок соответствует таблице на текущей странице; кнопка возвращается в нормальное состояние.

AC-2. Пустой результат (текущая страница):
- Дано: фильтр оставляет 0 строк на текущей странице.
- Когда: пользователь наводит курсор/фокус на кнопку «Экспорт в JSON».
- Тогда: отображается подсказка (tooltip) «Нет данных для экспорта» на фокусируемой обёртке; экспорт не запускается; кнопка нативно disabled.

AC-3. Индикатор загрузки:
- Дано: ≥1 видимая строка на текущей странице.
- Когда: экспорт запущен.
- Тогда: кнопка показывает индикатор загрузки; повторные клики не приводят к повторному экспорту; после завершения индикатор исчезает.

AC-4. Ошибка экспорта:
- Дано: сбой сериализации или сеть недоступна.
- Когда: пользователь запускает экспорт.
- Тогда: отображается тост «Не удалось выполнить экспорт. Попробуйте позже»; кнопка возвращается в нормальное состояние.
