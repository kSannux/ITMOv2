# Python export contract

Публичный модуль: `export_json.py` в корне ITMOv2. Runtime — только стандартная библиотека.

## export_visible_to_json

```python
export_visible_to_json(
    filtered_items: list[dict[str, object]],
    filters_applied: dict[str, object] | None = None,
) -> str
```

Вызов получает подготовленные строки текущей страницы с видимыми полями в текущем порядке. Самостоятельно не фильтрует, не сортирует, не выбирает страницу, не пишет файл. Только list допускается для внешнего списка; генераторы/None/строки/словари вместо списка — ошибка типа.

Результат — JSON-текст, пригодный для кодирования UTF-8, без BOM. Верхний уровень строго `export_date`, `total_items`, `filters_applied`, `data`. Пример:

```json
{
  "export_date": "2026-10-29T12:34:56Z",
  "total_items": 1,
  "filters_applied": {"q": "Иван", "active": true},
  "data": [{"name": "Иван", "value": "Infinity", "note": null}]
}
```

`total_items == len(filtered_items) == len(data)`, без пропуска ошибочных строк. Unicode остаётся читаемым; порядок строк сохраняется, порядок ключей не гарантируется. Входы не изменяются даже при ошибке. Возвращается весь документ либо исключение, частичного результата нет.

### Допустимые значения

- data: null/bool/string/int/конечный float, вложенные list/dict; все ключи строковые.
- float NaN/+Infinity/-Infinity на любой глубине data → "NaN"/"Infinity"/"-Infinity".
- datetime → UTC ISO 8601 Z, сохраняются дробные секунды; naive трактуется как UTC.
- date → YYYY-MM-DD; time → ISO-время UTC Z. Для time с фиксированным смещением используется опорная дата 2000-01-01 с отбрасыванием дня после конверсии; timezone без определённого смещения без даты не поддерживается.
- Decimal → точное str-значение; стандартные NaN/Infinity дают соответствующие строки.
- Enum → строковое/числовое value с дальнейшей нормализацией, проверяется до числовых/строковых базовых типов.
- bytes/bytearray → base64 ASCII.
- Остальные типы отклоняются. Скрытого fallback str нет.
- filters_applied: None → {}; иначе глубокая копия JSON-совместимого dict без преобразований. Ключи только строки; нечисловые float, tuple и другие специальные типы запрещены во входных фильтрах. Строки "NaN"/"Infinity" допустимы.

### Ошибки

| Условие | Исключение | Реакция вызывающего UI |
| --- | --- | --- |
| filtered_items == [] | ValueError("Empty dataset") | Не выдавать файл; без тоста «нет данных»; пересчитать состояние |
| Неверный тип списка, строки, фильтров или ключа | TypeError | Общий тост ошибки |
| Неподдерживаемое значение | TypeError | Общий тост ошибки |
| Нефинитное число в filters_applied | ValueError | Общий тост ошибки |
| Циклическая структура | ValueError | Общий тост ошибки |
| Превышение глубины рекурсии | RecursionError | Общий тост ошибки |

Проверка типа списка предшествует проверке пустоты; пустой список приводит к Empty dataset до обработки фильтров. Специальная реакция относится только к ValueError с сообщением Empty dataset; остальные ValueError не маскируются под пустой набор. Общий тост: «Не удалось выполнить экспорт. Попробуйте позже».

## make_export_filename

```python
make_export_filename(moment: datetime | None = None) -> str
```

None → текущее время UTC; datetime с timezone → UTC; naive → UTC. Неверный тип → TypeError. Результат export-YYYYMMDD-HHMMSS.json, только секунды. Функция не проверяет наличие файлов и не пишет на диск. Для имени с тем же моментом UI может разобрать export_date и передать его сюда. Одинаковые моменты в пределах секунды дают одинаковое имя; разрешение коллизии и поведение скачивания принадлежат UI.

## Граница UI

UI передаёт снимок страницы и столбцов, управляет Loading/Disabled/Active и скачиванием. При 0 строк библиотеку не вызывает: native disabled, tooltip на фокусируемой обёртке, без тоста. Фокус получает обёртка, а не нативно disabled-кнопка. На успешном запуске повторные клики блокируются до завершения, состояние затем пересчитывается по актуальной странице. Контракт содержит требования к интеграции; наличие работающего UI этим планом не подтверждается.

## Проверки контракта

Pytest должен проверять точные четыре поля; null/bool/Unicode; порядок и дубликаты; пустую страницу; независимость копии вложенных фильтров; отсутствие мутации при успехе/ошибке; вложенные специальные числа; нормализацию типов и UTC; отклонение неверных типов/ключей/циклов; повторное использование общей вложенной структуры без цикла; UTC-имя. Подробности запуска — [quickstart](../quickstart.md).
