# Data Model: export-filtered-json

## Row / Column

Row — словарь одной строки текущей страницы. Column — строковый идентификатор отображаемого поля; ключи Row соответствуют только отображаемым столбцам. Порядок ключей незначим. Значения допускают JSON-типы и специальные типы из [контракта](contracts/python-export.md). Отсутствующие поля не добавляются библиотекой; null сохраняется, а не превращается в строку. Подготовка нужного набора полей — ответственность UI.

Список строк упорядочен; повторяющиеся строки не удаляются, идентификатор id не обязателен. Список из пустых словарей допустим (есть строки, но нет отображаемых столбцов); пустой список запрещён. При виртуализации экспортируется вся текущая страница, а не только отрисованный участок. Без пагинации текущая страница — весь показанный результат.

## FiltersApplied

- Тип: словарь со строковыми ключами.
- Значения: null, boolean, string, integer, конечное number, массив или объект тех же типов.
- «filters_applied — копия словаря применённых фильтров на момент начала экспорта».
- None на входе заменяется {}; содержимое допустимого словаря не изменяется.
- Копия охватывает вложенные структуры; параметры сортировки в словарь фильтров не передаются.
- Нефинитные числа/специальные Python-типы здесь не принимаются; вызывающая сторона передаёт их JSON-совместимое представление заранее.

## ExportPayload

| Поле | Тип | Ограничение |
| --- | --- | --- |
| export_date | string | Момент формирования, ISO 8601 UTC с Z |
| total_items | integer | Положительное число; total_items == len(data) |
| filters_applied | object | Копия допустимого входного словаря |
| data | array of objects | Одна запись на входную строку, исходный порядок |

Верхний уровень содержит ровно эти четыре поля. Правила сортировки и порядок столбцов отдельными метаданными не передаются. export_date описывает формирование, не момент снимка UI; метаданные не обещают воспроизвести будущую выборку из изменившейся базы.

## Export filename

Строка export-YYYYMMDD-HHMMSS.json; дата/время UTC. Имя не входит в JSON. UI может передать момент export_date функции имени для согласованной временной метки. Совпадения имён допустимы и разрешаются механизмом сохранения.

## UI state (контракт вызывающего слоя)

| Состояние/событие | Результат |
| --- | --- |
| Нет активной операции, страница непустая | Active |
| Нет активной операции, страница пустая | Native Disabled; tooltip «Нет данных для экспорта» на фокусируемой обёртке; без тоста |
| Клик Active | Снимок страницы/полей/фильтров → Loading; повторный запуск блокируется |
| Успех | Передать содержимое на скачивание; пересчитать Active/Disabled по актуальной странице |
| ValueError("Empty dataset") | Не скачивать файл, без тоста «нет данных»; снять Loading и пересчитать состояние |
| Другая ошибка | Общий тост; снять Loading и пересчитать состояние; повтор доступен при непустой странице |

Loading имеет приоритет над правилом «есть строки → Active». Изменение интерфейса после начала операции не изменяет снимок текущего экспорта. Сам сериализатор синхронный и UI-состояниями не управляет.
