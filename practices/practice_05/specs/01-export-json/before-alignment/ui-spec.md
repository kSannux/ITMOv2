UI-спецификация: Экспорт видимых (отфильтрованных) данных в JSON

Короткое имя (short name): export-filtered-json

1. Обзор и цели

Цель: дать пользователю возможность экспортировать только те строки таблицы, которые видны после применения фильтров/поиска, в файл формата JSON одним действием.

Бизнес-ценность: пользователи быстро делятся и анализируют актуальный срез данных без ручной очистки/удаления «лишних» строк после экспорта.

Не цели (вне объёма):
- Плановые/пакетные экспорты, фоновые задания.
- Экспорт в другие форматы (CSV, XLSX и пр.).
- Настройка схемы/мэппинга полей вне текущей таблицы.

2. Акторы и контекст

- Актор: Пользователь интерфейса таблицы данных.
- Контекст: страница/экран с таблицей данных, полем поиска/фильтрации и кнопкой «Экспорт в JSON» на панели инструментов таблицы.

3. Элементы интерфейса

- Таблица данных:
  - Стандартные функции: отображение строк, пагинация (если есть), сортировка, настройка видимости столбцов.
- Поле поиска/фильтрации:
  - Однострочное поле с плейсхолдером «Поиск/Фильтр».
  - Применяет фильтрацию в реальном времени или по подтверждению (в соответствии с текущим UX-паттерном проекта).
- Кнопка «Экспорт в JSON»:
  - Текст: «Экспорт в JSON».
  - Состояния: активна, неактивна (disabled), загрузка (loading со спиннером/индикатором).
  - Подсказка (tooltip) при наведении: «Экспортирует текущие видимые строки в JSON».
  - Размещение: на панели инструментов таблицы рядом с полем поиска/фильтрации или справа в шапке таблицы (в одну линию).

4. Сценарии взаимодействия (User Scenarios)

Сценарий 1. Базовый экспорт отфильтрованных данных
1) Пользователь вводит фильтр в поле поиска/фильтрации.
2) В таблице остаются только видимые строки, например 2 из 10.
3) Кнопка «Экспорт в JSON» активна.
4) Пользователь нажимает «Экспорт в JSON».
5) Кнопка переходит в состояние загрузки (спиннер), повторные клики блокируются.
6) После завершения операции начинается скачивание файла JSON.
7) Кнопка возвращается в обычное состояние.

Ожидаемый результат: скачан JSON-файл, содержащий только 2 отфильтрованные строки, в текущем порядке сортировки.

Сценарий 2. Пустой результат фильтрации
1) Пользователь вводит фильтр, в результате чего видимых строк нет (0).
2) Кнопка «Экспорт в JSON» становится неактивной (disabled).
3) При попытке клика (например, через клавиатуру, тач или при интеракции по контролу) отображается тост-уведомление: «Нет данных для экспорта».

Ожидаемый результат: экспорт не запускается, пользователь информирован о причине.

Сценарий 3. Длительная операция экспорта
1) Пользователь запускает экспорт на большом наборе видимых строк.
2) Пока идёт экспорт, кнопка показывает индикатор загрузки; повторный запуск недоступен.
3) По завершении пользователь получает файл.

Ожидаемый результат: понятная индикация процесса; отсутствие дубликатов экспорта из-за повторных кликов.

Сценарий 4. Ошибка экспорта
1) Пользователь запускает экспорт.
2) Возникает ошибка (например, сеть недоступна).
3) Пользователь видит тост-уведомление: «Не удалось выполнить экспорт. Попробуйте позже». Кнопка возвращается в обычное состояние.

Ожидаемый результат: пользователь проинформирован о сбое и может попробовать снова.

5. Поведение и правила

- Что экспортируется:
  - Только строки, видимые после применения фильтров/поиска на текущем экране (без скрытых по фильтрам строк).
  - Порядок строк в JSON соответствует текущему порядку в таблице (с учётом сортировки).
  - Набор столбцов по умолчанию соответствует текущему набору отображаемых столбцов и их текущему порядку отображения (см. Допущения).
- Формат файла:
  - Имя файла по умолчанию: «export-YYYYMMDD-HHMMSS.json».
  - Содержимое: JSON-массив объектов; каждая строка таблицы — один объект, ключи соответствуют идентификаторам/заголовкам столбцов.
- Состояния кнопки «Экспорт в JSON»:
  - Active: есть ≥1 видимая строка.
  - Disabled: 0 видимых строк; при попытке взаимодействия показывать тост «Нет данных для экспорта».
  - Loading: экспорт инициирован; кнопка недоступна до завершения.
- Индикатор загрузки:
  - Визуально заменяет/дополняет текст кнопки (иконкой-спиннером) до завершения экспорта.
- Уведомления:
  - Успех: без всплывающих уведомлений (достаточно старта загрузки файла).
  - Пустой результат: тост «Нет данных для экспорта».
  - Ошибка: тост «Не удалось выполнить экспорт. Попробуйте позже».
- Доступность (Accessibility):
  - Кнопка фокусируемая, доступна с клавиатуры; состояния и подписи понятны скринридерам.
  - Тосты не блокируют управление и автоматически скрываются через короткий интервал.

6. Краевые случаи и состояния

- 0 видимых строк: кнопка disabled; при попытке клика отображается тост «Нет данных для экспорта».
- Длительный экспорт (>5 секунд): индикатор загрузки продолжает отображаться до окончания; повторный экспорт не запускается.
- Смена фильтра во время экспорта: до завершения текущего экспорта изменить результат нельзя; после завершения состояние кнопки пересчитывается по актуальным видимым данным.
- Большие наборы данных: поведение идентично; пользователь видит только индикатор, без дополнительных диалогов.

7. Функциональные требования (тестируемые)

FR-1. Кнопка «Экспорт в JSON» активна, когда количество видимых строк ≥1; иначе — disabled.

FR-2. При нажатии активной кнопки запускается экспорт только текущих видимых строк; невидимые по фильтрам строки в файл не попадают.

FR-3. Во время экспорта кнопка отображает индикатор загрузки и не допускает повторного запуска до завершения операции.

FR-4. Если количество видимых строк = 0, при попытке клика отображается тост «Нет данных для экспорта», экспорт не запускается.

FR-5. Экспортируемые данные следуют текущему порядку сортировки таблицы.

FR-6. Имя файла по умолчанию формируется как «export-YYYYMMDD-HHMMSS.json».

FR-7. Формат JSON — массив объектов; количество объектов равно количеству видимых строк на момент начала экспорта.

FR-8. Текстовые сообщения локализованы: «Экспорт в JSON», «Нет данных для экспорта», «Не удалось выполнить экспорт. Попробуйте позже».

FR-9. Доступность: кнопка доступна с клавиатуры, состояния фокусировки и недоступности различимы; тосты не перехватывают фокус надолго и закрываются автоматически.

8. Критерии успеха (измеримые, проверяемые)

- SC-1. Пользователь получает файл экспорта не позднее чем через 5 секунд в 95% случаев при объёме до 5 000 видимых строк.
- SC-2. В 100% случаев при 0 видимых строк кнопка недоступна и при попытке клика отображается тост «Нет данных для экспорта».
- SC-3. В 100% случаев экспортируемый JSON содержит только видимые строки и соответствует текущему порядку сортировки.
- SC-4. В ходе юзабилити-тестов не менее 80% пользователей находят кнопку «Экспорт в JSON» и успешно завершают экспорт за ≤15 секунд, без инструкций.

9. Приёмочные сценарии (Acceptance)

AC-1. Базовый экспорт:
- Дано: 10 строк; фильтр оставляет 2 строки.
- Когда: пользователь нажимает «Экспорт в JSON».
- Тогда: скачивается файл .json с массивом из 2 объектов; порядок соответствует таблице; кнопка возвращается в нормальное состояние.

AC-2. Пустой результат:
- Дано: фильтр оставляет 0 строк.
- Когда: пользователь пытается нажать кнопку (мышь/клавиатура/тач).
- Тогда: отображается тост «Нет данных для экспорта»; экспорт не запускается.

AC-3. Индикатор загрузки:
- Дано: видимые строки ≥1.
- Когда: экспорт запущен.
- Тогда: кнопка показывает индикатор загрузки; повторные клики не приводят к повторному экспорту; после завершения индикатор исчезает.

AC-4. Ошибка экспорта:
- Дано: сеть недоступна.
- Когда: пользователь запускает экспорт.
- Тогда: отображается тост «Не удалось выполнить экспорт. Попробуйте позже»; кнопка возвращается в нормальное состояние.

10. Сущности и данные (Key Entities)

- Строка (Row): объект данных, соответствующий одной записи таблицы.
- Столбец (Column): поле/атрибут строки; набор отображаемых столбцов определяет структуру экспортируемого объекта.

11. Допущения (Assumptions)

- Экспорт включает только видимые строки и только отображаемые столбцы в текущем порядке. Если требуется экспорт всех столбцов, это будет оговорено отдельно на уровне требований.
- Экспорт запускает стандартное скачивание файла без дополнительных диалогов подтверждения.
- Применённые фильтры и сортировки фиксируются на момент нажатия кнопки экспорта.

12. Риски и зависимости

- Зависимость от корректной логики фильтрации/сортировки таблицы.
- Возможные ограничения объёма данных будут учтены при планировании производительности.

13. Тексты интерфейса (локализация)

- Кнопка: «Экспорт в JSON».
- Тост (пустой результат): «Нет данных для экспорта».
- Тост (ошибка): «Не удалось выполнить экспорт. Попробуйте позже».
