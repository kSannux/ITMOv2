# Спецификация логики: экспорт текущей страницы в JSON

Короткое имя: `export-filtered-json`.

Источник истины: [общий контракт](spec.md).
Детали типов и ошибок: [Python-контракт](contracts/python-export.md).
[Версия до согласования](before-alignment/logic-spec.md).

## 1. Цель и ответственность

`export_json.py` формирует JSON из подготовленного снимка страницы.
Фильтрация, сортировка, пагинация, выбор столбцов, HTTP и скачивание
принадлежат UI/интеграции, а не библиотеке. Runtime библиотеки — stdlib.
Flask — отдельная зависимость сайта.

## 2. API и данные

```python
export_visible_to_json(
    filtered_items: list[dict[str, object]],
    filters_applied: dict[str, object] | None = None,
) -> str
make_export_filename(moment: datetime | None = None) -> str
```

- Внешний контейнер — только list; каждая строка — dict со строковыми ключами.
- Список относится только к текущей странице, ключи — только видимые поля.
- Порядок строк и дубликаты сохраняются; id не обязателен.
- Непустой список пустых dict допустим; пустой список запрещён.
- Фильтры: None → {}; иначе глубокая копия JSON-совместимого dict
  без преобразования содержимого. Ключи строковые; значения null/bool/string/
  int/конечный float и вложенные list/dict. Tuple, специальные типы и
  нечисловые float в фильтрах запрещены. Строка «NaN» допустима.
- Входы не изменяются при успехе и ошибке.

## 3. Результат

Возвращается весь JSON-текст UTF-8 без BOM либо исключение; нет частичного
результата и молчаливого пропуска строк. Ровно четыре поля:

| Поле | Правило |
| --- | --- |
| export_date | Момент формирования в UTC ISO 8601 с Z |
| total_items | len(filtered_items) == len(data) |
| filters_applied | Копия фильтров без описания сортировки |
| data | Нормализованные строки в исходном порядке |

Unicode читаем, null остаётся null; порядок ключей не гарантируется.
Имя файла — `export-YYYYMMDD-HHMMSS.json` по UTC. Для helper None — текущее
время, naive datetime — UTC, aware datetime переводится в UTC; иной тип —
TypeError. Helper не пишет файлы и не устраняет совпадения имён в пределах секунды.

## 4. Нормализация data

- JSON-примитивы и вложенные list/dict сохраняются; ключи только строки.
- NaN/+Infinity/−Infinity на любой глубине → «NaN»/«Infinity»/«-Infinity»
  без ошибки по этой причине.
- datetime → UTC ISO 8601 Z с сохранением дробных секунд; naive — UTC.
- date → YYYY-MM-DD; time → UTC ISO-время Z. Фиксированное смещение
  переводится с опорной датой 2000-01-01, день затем отбрасывается.
  Timezone, не определяющая offset без даты, не поддерживается.
- Decimal → точное строковое значение; специальные числа → соответствующие строки.
- Enum → нормализация value, проверяется до базовых числовых/строковых типов.
- bytes/bytearray → base64 ASCII.
- Нет автоматического asdict/to_dict или fallback str для произвольных объектов.
  Иные значения отклоняются.

## 5. Алгоритм и ошибки

1. Проверить тип списка, затем пустоту (до обработки фильтров).
2. Валидировать и скопировать фильтры.
3. Валидировать и рекурсивно нормализовать все строки в новые структуры.
4. Создать metadata и сериализовать строгий JSON без нестандартных NaN-токенов.
5. Вернуть документ. Запись/доставка — вызывающая сторона.

| Условие | Ошибка | Реакция UI |
| --- | --- | --- |
| Пустой list | ValueError("Empty dataset") | Пересчитать состояние, без тоста |
| Неверный тип/ключ, неподдерживаемое значение | TypeError | Общий тост ошибки |
| Нефинитный float в фильтрах | ValueError | Общий тост ошибки |
| Цикл | ValueError | Общий тост ошибки |
| Превышение глубины | RecursionError | Общий тост ошибки |

Общий тост: «Не удалось выполнить экспорт. Попробуйте позже».
Повторное использование вложенного объекта без цикла допускается.
Только точный Empty dataset имеет специальное отображение.

## 6. Проверка и критерии успеха

Проверить metadata, порядок/дубликаты/видимые поля, пустой список,
копирование фильтров, Unicode/null, типы и UTC, специальные числа,
неверные входы, циклы и общие вложенные структуры, отсутствие мутации,
детерминированное UTC-имя. HTTP-проверки покрывают выдачу attachment,
пустой запрос, неверные данные и сбой сериализатора.

SC-4 общего контракта: ≤2 с в 95% измерений на ≤10000 строк.
Benchmark: прогрев + 20 измерений фиксированных 10000 строк,
не менее 19 результатов ≤2 с. Этот результат не доказывает время
браузерного скачивания SC-1. SC-5 проверяется также на кириллице/эмодзи,
но малый набор примеров не является статистической оценкой 99%.

Автотесты не заменяют [сквозную проверку UI](../../reports/e2e-report-template.md).
Нет авторизации, хранения, аудита, маскирования PII и иных форматов экспорта.
