# UI-спецификация: экспорт текущей страницы в JSON

Короткое имя: `export-filtered-json`.

Источник истины: [общий контракт](spec.md), включая FR-1–FR-11 и SC-1–SC-5.
Эта спецификация уточняет обязанности UI, а не меняет общий контракт.
[Версия до согласования](before-alignment/ui-spec.md).

## 1. Цель и границы

Пользователь экспортирует только строки текущей страницы после фильтрации и
сортировки, только отображаемые столбцы. Сохраняется порядок строк; порядок
ключей JSON незначим. Экспорт всех страниц, CSV/XLSX, фоновый экспорт,
авторизация, аудит и хранение файлов вне объёма.

Локальное демо — Flask-сайт с таблицей сотрудников. Поиск, сортировка,
пагинация и выбор столбцов выполняются в браузере. Набор сотрудников
демонстрационный и не является постоянным хранилищем.

## 2. Элементы интерфейса

- Таблица с сортируемыми заголовками и различимым направлением сортировки.
- Поле с подписью и placeholder «Поиск/Фильтр».
- Выбор видимых столбцов; скрытые поля не передаются в экспорт.
- Пагинация и выбор размера страницы.
- Кнопка «Экспорт в JSON» рядом с поиском.
- Фокусируемая обёртка кнопки с tooltip, доступным мышью и клавиатурой.
- Неблокирующий тост ошибки с автоматическим скрытием, без переноса фокуса.

## 3. Состояния

| Состояние | Условие | Поведение |
| --- | --- | --- |
| Active | На текущей странице ≥1 строки и нет запроса | Кнопка доступна с клавиатуры; подсказка «Экспортирует текущие видимые строки в JSON» |
| Disabled | На текущей странице 0 строк | Native disabled; tooltip «Нет данных для экспорта» на фокусируемой обёртке; нет запроса, скачивания и тоста |
| Loading | Запрос начат, но ещё не завершён | Индикатор загрузки, повторный запуск заблокирован |

После успеха/ошибки состояние пересчитывается по актуальной странице.
Изменение фильтра во время запроса не меняет уже отправленный снимок.
Tooltip и тост автоматически скрываются и не перехватывают фокус надолго.

## 4. Контракт UI ↔ логика

При нажатии UI фиксирует снимок:

- `data`: список строк только текущей страницы, только видимые ключи, в порядке таблицы;
- `filters_applied`: копия словаря применённых фильтров; без фильтров `{}`;
- сортировка влияет на порядок строк, но не включается в метаданные.

В Flask-демо UI делает `POST /export` с JSON `{data, filters_applied}`.
Flask вызывает `export_visible_to_json(data, filters_applied)`.
При успехе ответ — JSON attachment, UI инициирует скачивание.

Файл — **объект**, не массив: ровно `export_date`, `total_items`,
`filters_applied`, `data`. `total_items == len(data)`; timestamp UTC с `Z`.
Имя: `export-YYYYMMDD-HHMMSS.json` по UTC; в демо имя и metadata относятся
к одному моменту. Разрешение коллизий скачивания остаётся браузеру.
Unicode/null сохраняются; специальные значения нормализует библиотека
по [Python-контракту](contracts/python-export.md).

## 5. Ошибки

- При 0 строк UI не вызывает логику: нет тоста «нет данных».
- Если логика всё же выдала точное `ValueError("Empty dataset")`, UI
  пересчитывает состояние без тоста. В Flask: HTTP 409, `error=empty_dataset`.
- Иные ошибки нормализации/сериализации и сетевые сбои: тост
  «Не удалось выполнить экспорт. Попробуйте позже», файл не выдаётся,
  повторная попытка доступна после завершения запроса.
- Flask возвращает 400 для неверного тела, 422 для ошибок данных,
  500 для непредвиденной ошибки; UI не показывает внутренние детали.

## 6. Приёмочные сценарии

1. **AC-1 / успех:** фильтр оставляет две строки; скрыть столбец и отсортировать.
   Скачанный JSON содержит только эти строки/поля в том же порядке,
   верные фильтры и metadata; кнопка восстанавливается.
2. **AC-2 / пусто:** фильтр оставляет 0 строк. Кнопка native disabled;
   tooltip виден при наведении и Tab-фокусе на обёртке; POST/тоста/файла нет.
3. **AC-3 / загрузка:** замедлить сеть и нажать экспорт повторно.
   Есть индикатор, только один POST. После завершения индикатор исчезает.
4. **AC-4 / ошибка:** отключить сеть после загрузки сайта. Появляется общий
   тост; кнопка восстанавливается; после восстановления сети повтор успешен.
5. **Страница:** экспорт второй страницы не содержит строки других страниц.
6. **Снимок:** смена фильтра во время запроса не изменяет файл старого
   запроса; состояние кнопки после завершения соответствует новой странице.
7. **Нет видимых столбцов:** при наличии строк экспорт допустим;
   `data` содержит соответствующее количество пустых объектов.

## 7. Критерии успеха и доказательства

Применяются критерии общего контракта: SC-1 — начало скачивания ≤5 с
в 95% запусков при ≤5000 строк; SC-2 — disabled/tooltip при пустой странице;
SC-3 — точная страница и порядок; SC-5 — сохранность Unicode.
SC-4 относится к библиотеке. Малое демонстрационное множество и единичный
ручной запуск не доказывают процентные критерии.

Проверки записываются в [шаблон сквозного отчёта](../../reports/e2e-report-template.md).
Наличие этой спецификации не означает, что ручные проверки уже выполнены.
